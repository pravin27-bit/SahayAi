
# SahayAI – Website Explanation Script

This is SahayAI, an AI-powered welfare scheme discovery and application assistance platform.

The main problem we are solving is that government welfare schemes are often difficult to discover and understand. People may not know which schemes they are eligible for, what documents they need, or how to apply.

When the user enters our website, they can create their Citizen Profile by providing basic details such as age, income, occupation, location, education, and family information.

Based on this profile, SahayAI uses AI to identify potentially relevant government schemes. Instead of simply showing a long list of schemes, our system explains why a particular scheme may be suitable for the user.

For example, it can show which eligibility conditions the user meets and which information is still missing.

Our Document Readiness feature then checks the documents required for the selected scheme and highlights what the user already has and what is still required.

The user can also interact with our AI Assistant using natural language. They can ask questions like, “Which schemes can help my family?” or “What documents do I need for this scheme?” and receive a simple, understandable response.

Finally, SahayAI provides application preparation guidance and directs users toward the relevant official government source for the actual application.

Our goal is to make welfare benefits easier to discover, easier to understand, and easier to access.
